Key Findings

🔧 Predictive Maintenance

XGBoost achieved 94% RUL accuracy. Only 5 sensors (EGT, fan speed, core speed, LPC temp, HPC temp) capture 90% of predictive signal — verified via recursive feature elimination.

📊 NLP Classification

TF-IDF + Naive Bayes scores 68% on 20 categories and runs 400× faster than BERT. Tested on 18,846 real Usenet posts. Primary error: sci.electronics vs sci.crypt overlap.

📈 Demand Forecasting

Ensemble (ARIMA + XGBoost) outperformed either alone by 18% MAE. Calendar patterns drive 73% of rental variance. Reduces overstocking by 22% on low-demand windows.

💡 Business Impact

5-sensor subset cuts IoT infrastructure by 75%. CPU text classification eliminates GPU dependency. Predictable demand patterns enable 22% inventory reduction while maintaining 98% peak availability.

Built with real public data — NASA C-MAPSS, Citi Bike, 20 Newsgroups. Zero synthetic records.
