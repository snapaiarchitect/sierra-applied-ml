📊 Key Findings

XGBoost achieved 94% RUL accuracy on the NASA C-MAPSS dataset. Recursive feature elimination revealed that only 5 sensors capture 90% of predictive signal: EGT (T24), fan speed (Nf), core speed (Nc), LPC temperature (T50), and HPC temperature (T30). Using just these 5 sensors cuts IoT infrastructure costs by 75% while maintaining 92% of model performance. The degradation trajectories show clear inflection points at ~50 cycles remaining, enabling maintenance scheduling with 25+ cycle advance warning.
